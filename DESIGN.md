# DESIGN — English Academy

## Design Direction

English Academy menggunakan konsep:

**Modern English Learning Platform**

Desain harus terlihat:

- Modern
- Clean
- Professional
- Friendly
- Educational
- Premium

---

## Visual Identity

Website harus memberikan kesan:

"Belajar bahasa Inggris dengan cara modern dan menyenangkan."

---

## Color Palette

### Primary

`#2563EB`

Digunakan untuk:

- Primary button
- Links
- Active states
- Important elements

### Secondary

`#0F172A`

Digunakan untuk:

- Headings
- Navigation
- Dark sections

### Accent

`#F59E0B`

Digunakan untuk:

- Highlights
- Ratings
- Important badges

### Background

`#F8FAFC`

### White

`#FFFFFF`

### Success

`#22C55E`

### Error

`#EF4444`

### Muted

`#64748B`

---

## Typography

Gunakan font modern seperti:

- Inter
- Poppins

Heading:

Bold / 700

Subheading:

Semi Bold / 600

Body:

Regular / 400

---

## Layout

Maximum content width:

1200px

Gunakan:

- Consistent spacing
- Generous whitespace
- Clear visual hierarchy
- Responsive grid
- Rounded cards

---

## Border Radius

Small:

8px

Medium:

12px

Large:

20px

---

## Hero Section

Hero menggunakan layout dua kolom pada desktop.

### Left

- Badge
- Heading
- Description
- CTA buttons

### Right

- Student learning image
- Floating statistic
- Floating course card

Pada mobile menjadi satu kolom.

---

## Navbar

Navbar:

- Logo
- Home
- Courses
- Tutors
- Pricing
- About

Right:

- Login
- Get Started

Navbar bersifat sticky.

---

## Course Cards

Card memiliki:

- Thumbnail
- Level badge
- Course title
- Description
- Tutor
- Rating
- Duration
- Price
- CTA

Hover effect:

- Slight elevation
- Soft shadow
- Image zoom ringan

---

## Dashboard

Student dashboard menggunakan:

Sidebar + Main Content

Sidebar:

- Dashboard
- My Courses
- Lessons
- Quiz
- Progress
- Certificates
- Profile
- Settings
- Logout

---

## Mobile

Pada mobile:

- Navbar menjadi hamburger
- Sidebar menjadi drawer
- Cards menjadi satu kolom
- Hero menjadi vertical
- Buttons menjadi full width jika diperlukan

---

## Animation

Gunakan animasi ringan:

- Fade
- Slide
- Hover
- Scale
- Smooth transition

Hindari animasi yang mengganggu pembelajaran.

---

## Design Principles

Prioritas:

1. Usability
2. Readability
3. Accessibility
4. Consistency
5. Visual hierarchy
6. Performance
