# English Academy

## Modern English Learning Platform

English Academy adalah rancangan platform kursus bahasa Inggris berbasis web yang modern, profesional, responsif, dan mudah digunakan.

Project ini dirancang sebagai platform pembelajaran bahasa Inggris yang nantinya dapat dikembangkan menjadi aplikasi EdTech lengkap.

---

## 🎯 Project Goal

English Academy bertujuan menyediakan pengalaman belajar bahasa Inggris yang terstruktur melalui:

- Online Courses
- Interactive Lessons
- Video Learning
- Quiz
- Progress Tracking
- Student Dashboard
- Tutor
- Certificate
- Admin Dashboard

## 📌 Development Strategy

Agar pembangunan aman dan bertahap, fase-fase **frontend dikerjakan lebih dulu** menggunakan **mock data lokal**:

- Direktori `src/data` berisi data contoh (courses, tutors, quiz, testimonial).
- **Backend (Node.js + Express REST API), authentication server-side, dan PostgreSQL diintegrasikan setelah frontend selesai** (Fase 12).
- **Video learning pada tahap awal menggunakan placeholder/mock video**, diganti video asli pada Fase 12 atau fase Advanced Features.

### Advanced Features (Pasca Frontend & Backend Dasar)

Dikerjakan setelah infrastruktur inti selesai:

- Payment Gateway
- Live Class
- Video Learning (file asli / streaming)
- Notifications
- Chat
- AI English Tutor
- Subscription System
